# Downloads site

A static page that offers the ZKNetwork desktop client and the `zknet` CLI for the visitor's platform. It reads
the platform in the browser (User-Agent Client Hints, else the User-Agent string), and each component's current
release from a `downloads.json`. It sets no cookies and loads nothing but its own files and those release files.

```sh
pnpm nx run downloads:dev          # http://localhost:3003
pnpm nx run downloads:build        # snapshot, then dist/: the whole site
pnpm nx run-many -t test,typecheck,lint -p downloads
```

## Settings

`.env` beside this file (git-ignored; start from `.env.example`). Vite reads it at build time and every value ends
up in the page. A link left empty is hidden.

## Release files

Each component's current release on a channel is one file, `<VITE_DOWNLOADS_BASE>/<id>/<channel>/downloads.json`
(`src/manifest.ts`'s `Downloads`):

```json
{
  "schema": 1,
  "id": "client-cli",
  "channel": "beta",
  "version": "0.1.0-beta.1",
  "date": "2026-10-29",
  "notes": "https://…/releases/tag/client-cli%400.1.0-beta.1",
  "checksums": "https://…/checksums.txt",
  "assets": [
    {
      "os": "linux",
      "arch": "x86_64",
      "kind": "binary",
      "name": "zknet_0.1.0-beta.1_linux-amd64",
      "url": "https://…/zknet_0.1.0-beta.1_linux-amd64",
      "size": 1857496,
      "sha256": "…"
    }
  ]
}
```

`os` is `linux`, `macos` or `windows`; `arch` is `x86_64`, `arm64` or `universal`; `kind` is `dmg`, `exe` (an
installer), `AppImage`, `deb`, `rpm`, `binary` or `archive`. The page reads `client` and `client-cli`; the install
script reads `client-cli`.

The page fetches these files when it loads. `snapshot` (run by `build`) bakes a copy into the site under
`public/downloads/`, which the page falls back to when the live files don't answer.

## Targets

| target                           | does                                                                |
| -------------------------------- | ------------------------------------------------------------------- |
| `snapshot`                       | copies the current `downloads.json` files into `public/downloads/`  |
| `build`                          | `snapshot`, then the static site in `dist/`, with Pages' `_headers` |
| `dev`, `preview`, `serve-static` | Vite's dev server and previews (inferred)                           |
| `test`                           | vitest: platform detection and download choice (inferred)           |
| `typecheck`, `lint`              | `tsc` and oxlint (inferred)                                         |

`_headers` is generated by the build: a Content-Security-Policy that allows only this origin, plus the origin of
`VITE_DOWNLOADS_BASE` for `connect-src`; `Referrer-Policy: no-referrer`; `X-Content-Type-Options: nosniff`.
