A `LICENSE` file in a subdirectory governs the tree beneath it. The
`license` field of each `package.json` and `Cargo.toml` declares the same
license as the tree the manifest sits in.

Some files include third-party code that keeps its own license and copyright
notice; a `NOTICE` file next to them lists those files (for example
[`packages/anon-rpc/specifier/NOTICE`](packages/anon-rpc/specifier/NOTICE)).
